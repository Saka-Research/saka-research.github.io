---
title: "New preprint: To Learn is to Wander"
date: 2026-10-05
summary: We released Wander, a single graph foundation model for node classification, link prediction, and knowledge-graph reasoning built on random walks.
---

Our new preprint, [To Learn is to Wander: Learning Across Graphs and Tasks with Random Walks](https://arxiv.org/abs/2610.06694),
introduces Wander, a single graph foundation model that uses random walks as a shared interface across graphs and tasks.
Code is available on [GitHub](https://github.com/louistichelman/wander-gfm).

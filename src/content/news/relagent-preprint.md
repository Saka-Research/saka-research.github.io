---
title: "New preprint: RelAgent"
date: 2026-05-08
summary: RelAgent uses LLM agents as data scientists for relational learning, producing predictors that are fast and interpretable.
---

In [RelAgent](https://arxiv.org/abs/2605.07840), an LLM agent explores a relational database, writes SQL feature programs,
and selects a classical model. The final predictor runs without any LLM calls and is interpretable by construction.

---
title: "New preprint: Bringing Graphs to the Table"
date: 2025-09-08
summary: "Node classification reformulated as a tabular problem, so that tabular foundation models can classify nodes zero-shot."
---

In [Bringing Graphs to the Table: Zero-shot Node Classification via Tabular Foundation Models](https://arxiv.org/abs/2509.07143), with Xingyue Huang and Ben Finkelshtein, each node becomes a row with feature, structure, and label columns, so that tabular foundation models can perform zero-shot node classification via in-context learning.
